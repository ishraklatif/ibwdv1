# Sprint 3 free-stage report and verdict

**Verdict: READY FOR PAID A/B** — no blocking condition of `SPRINT3_gate_definition.md` §9 holds, and every required piece of
evidence is linked below. **Nothing paid was run.** Starting the paid A/B needs your explicit instruction; pushing the local
commits needs a separate one. The caveats in §8 are not blockers but bound what the result can claim.

Frozen configuration measured: IBWD edge-build version **27** (export commit recorded in each export; tree clean, `dirty=false`),
five repositories at their pinned SHAs, manifests and gate definition v2.

## 1. Scope, decisions applied

Manifests (`benchmarks/manifests/<repo>.json`, `{repo_sha, included_files, excluded_files:[{file,reason,evidence}]}`) are the single
scope for IBWD exports, oracle graphs and expected answers. Sphinx is Python-only (243 files); its 142 JavaScript files are kept in
`sphinx_js_classification.json` (34 minified stemmers + vendored css3-mediaqueries verified; 70 translation catalogs accounted for
separately; no hand-written file excluded for long lines). Headline strata Q1/Q2/Q3/small-function; Celery is the negative control;
no-static-use and hard-case checks are free diagnostics (§6). Weights, metric and the 120-session plan are unchanged.

## 2. Resolver changes (default edge policy + defects found by the oracles)

The frozen policy is implemented and tested: `resolved` = import-map / same-module / inherited (+ IMPORTS); `candidate` = unique-name /
suffix / inherited-behind-an-external-base (dunder names only); fuzzy disabled; default callers/dependents/trace-path use resolved edges;
`include_candidates=true` labels candidates; CALLS-only default chains; CALLS and REFERENCES both kept; `sum(1/confidence)` is a
heuristic cost.

Full-repository comparison against independent oracles found and fixed, with regression tests, these further defects (each was
confirmed against source before fixing): parameters / assigned locals / nested defs / comprehension variables resolved to same-named
module functions (Celery, Sphinx); inherited lookup used breadth/depth order instead of C3 MRO; a class alias as a base
(`_Base = Base[T]`); class-body names resolving to imports instead of earlier class members; generic-base arguments, `del name` and
overload signatures counted as value uses; `except X as e`, parameter defaults, chain heads (`Cls.CONST`), `export default X`,
`self.prop.method()` reads not recorded; TypeScript: definitions inside an IIFE initialiser were invisible, `import()` outside a
declarator and `import {a}; export {a}` barrels were not followed; a hand-written file whose comment says "imagine this file is
autogenerated" was classified generated and dropped (10 Bulletproof IMPORTS edges). Build version 14 → 27.

Oracle-side defects (adapter fixes, exact fixtures): class-body owner, nested-symbol collisions, property term symbols, type aliases /
type comments / writes counted as uses, parenthesised callees, `self` lexical only as a method's own parameter, imported variables
inferred not lexical, `__slots__` names, nested-class INHERITS sources.

## 8. Caveats that do not block but limit the claim

1. **The five repositories are development data.** The resolver was changed in response to them repeatedly; the figures above are
   optimistic for unseen code. TypeDoc is reserved as the confirmation repository (inspected during early screening, not used for local resolver tuning); results there must be reported separately.
2. Supported scope was defined partly after seeing misses (e.g. `self` of a module-level function is type-inferred). Both raw supported
   recall and *broader* coverage are reported; broader is 75.3–75.8% on Sphinx/Scrapy CALLS.
3. Adjudicated precision drops 3 out-of-scope items from denominators (Sphinx 1, Celery 1, RTK 1); raw is next to it everywhere.
4. Oracle graphs are `complete: false` static oracles; no oracle sees dynamic dispatch, decorators registering handlers, or reflection.
5. Runtime coverage is partial (selected suites; one reactor; no worker integration) and the profiler misses processes that die by signal.
6. IBWD stores no call-site positions, so comparison is pair level; the TS adapter deviates from SCIP as noted.
7. The paid harness for the 20 golden tasks (reading `ground_truth/*.yaml` and grading deterministically) is **not built**; that is
   set-up for the paid run, not part of this free stage. Startup overhead break-even is `B ≥ 18,764 + 3I` tokens (gate §5).
